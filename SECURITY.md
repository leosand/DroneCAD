# Security Policy

## Supported versions

Only the latest release and the `main` branch receive security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting: **Security tab > Report a vulnerability** on this repository.

Expect an acknowledgement within 5 business days.

## Scope specific to agentic tooling

DroneCAD lets an LLM agent trigger actions (scripts, CAD operations, simulation) through MCP tools. Please report in particular:

- Prompt injection leading to unintended command execution.
- File access outside the intended workspace.
- Leakage of environment variables or secrets.
- Unsafe defaults in `docker-compose.yml` or `.mcp.json`.

## Safety notice

Outputs generated by an LLM must be reviewed by a human before any fabrication or use on physical hardware.
